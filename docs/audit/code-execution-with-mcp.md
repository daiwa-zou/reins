## Gaps
- No data-stays-in-runtime mode: add a `run_script` tool that executes a script under the sandbox and returns only its stdout (capped) while writing the full result to `.reins/out/<id>`, and prompt the builder to use it for large or chained data instead of reading files into context.
- No PII tokenization: add a pass in `loop.ts:402-405` that replaces e-mail, phone and card patterns in tool results with `[EMAIL_n]` placeholders kept in a per-run map, restoring them when a placeholder appears in a later tool input; make it a `components` switch so it can be ablated.
- Skills are not written by the agent: add a `save_skill(name, description, body)` tool confined to `.reins/skills/<name>/SKILL.md` and mention it in the BUILDER prompt after a fix round; the Harness Skills list already shows workspace skills.
- No live logs for long commands: stream `child.stdout` chunks as `tool.progress` events (bounded) so the Stage row can show the tail of a 10-minute test run while it runs.
- `tool_search_tool_regex` has no detail level: once external MCP servers are allowed (see advanced-tool-use), expose them via the deferred-tool path and record `bytesIn`/`bytesOut` on `tool.result`.
- The SDK engine drops text beyond 24,000 chars (`claudeCodeLoop.ts:340`) instead of saving it: call `saveFullOutput` there too so the "full output" link works on both engines.
