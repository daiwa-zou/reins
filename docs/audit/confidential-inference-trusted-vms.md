## Gaps
- Decisions are not all logged: make `gate()` emit a `guardrail.decision` for read-only and in-workspace allows too (`loop.ts:477-480`), so the Guardrails tab is a complete record, and collapse the two gate implementations into one function both engines call.
- No tamper evidence: add `prevHash`/`hash` (sha256 of the previous line and this one) to every event in `RunBus.emitEvent`, a `GET /api/runs/:id/export` that bundles `events.jsonl`, `config.json`, tool outputs and the prompt texts, and a verifier in `lessons:check` style (`npm run runs:verify`).
- The key re-enters the agent's environment on the SDK engine (`claudeCodeLoop.ts:184`): prefer the CLI login (`CLAUDE_CONFIG_DIR`) and drop `ANTHROPIC_API_KEY` from `env` when a login exists.
- No production mode: add `guardrail.mode: "production"` that rejects `trust`, custom allow patterns and `allowNetwork` on the direct engine, shows a badge in `RunHeader`, and is the default for saved presets marked `shared`.
- Trace lacks tool and skill provenance: hash each tool schema and each skill body read, and record `toolsHash`, `skillsHash`, `stageLessonsHash` in the request-shape note so a run can be checked against what should have been running.
- Egress is unmeasured: when a local proxy exists (see the sandboxing audit) log destination and bytes per run as `note` events and show totals on the Guardrails tab.
- Name the trust boundary: add a `trustedCore` foundation to `shared/components.ts` listing the modules it covers (policy, classifier, bus, scrubbedEnv, confinePath) and keep those files free of tool execution so a reviewer knows what to read.
