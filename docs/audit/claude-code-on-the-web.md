## Gaps
- No domain allowlist: add `allowedDomains: string[]` to `GuardrailPolicy`, feed it to the SDK sandbox `network.allowedDomains` in `claudeCodeLoop.ts:215` and to a local egress proxy for the Seatbelt path; until a proxy exists, at least show the field and warn that the direct engine enforces it only via the command rules.
- No PR deliverable: add an optional wrap-up step (branch per run, `gh pr create` behind a `phase` approval) and surface the PR URL in the EndCard.
- Git credentials are reachable from the sandbox: deny reads of `~/.ssh` and `~/.git-credentials` in `seatbeltProfile`, and route `git push` through a helper that attaches credentials outside the sandbox.
- Two runs can target one workspace at once and share `.reins/`: refuse `createRun` while another live run owns the same workspace, or run each trial in a fresh worktree.
- No remote execution target: the `LoopOptions`/`ToolContext` seam (`loop.ts:29-40`, `registry.ts:15-24`) is where an SSH or container executor would plug in; document it as out of scope or add it.
- Unified budget: add a Reliability or sidebar tile that sums cost across runs for the day and, on the Claude Code engine, says that usage is counted against the subscription shared with the CLI.
