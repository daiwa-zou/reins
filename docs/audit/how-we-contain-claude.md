## Gaps
- Domain allowlist: `guardrail.allowedDomains: string[]` passed to the SDK `network.allowedDomains` and checked by `http_fetch` and the intake fetch; since Seatbelt cannot filter by host, keep shell network off whenever a list is set or route it through a local proxy.
- Credentials readable from the sandbox: add `(deny file-read* (subpath "~/.aws") (subpath "~/.ssh") (literal "~/.netrc") ...)` to the Seatbelt profile and a read-deny list in `confinePath`.
- No trust prompt: ask once per new workspace (approval kind `workspace`) before CLAUDE.md, `.claude/skills` and `.reins/*` are read, and record the decision in `settings.json`.
- `confinePath` is lexical: `realpathSync` the deepest existing ancestor of `abs` and re-check it under `realpathSync(workspace)`; fix the comment.
- No filesystem modes: `guardrail.fs: "rw" | "ro" | "rw-no-delete"` honoured by `write_file`/`edit_file` and a DENY on `rm` in `classifyBash`.
- Output inspection is regex-only and the SDK engine does not wrap: on a sniff hit run a one-shot classifier call over the output and wrap it in both engines.
- No egress record: log the host of every `http_fetch`/`WebFetch` and of `curl`/`wget` commands into a `network.access` note shown on the Guardrails tab.
- Persistent-state provenance: run `sniffInjection` over CLAUDE.md, AGENTS.md and `progress.md` at load and label the "Project notes" section with its source path.
- Local server is unauthenticated: bind to 127.0.0.1 and require a per-start token (printed at startup, held by the web app) on every mutating route.
