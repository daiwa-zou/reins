## Gaps
- Classifier coverage is regex-gated: in auto mode send every non-`SAFE_PREFIX` `bash` command, `http_fetch` URL and `delegate_scout` question to `classifyAction`, using the regex only as a fast pre-filter.
- No allow rules to drop: add `allowPatterns` to `GuardrailPolicy`, and when `mode === "auto"` ignore any pattern that matches a blanket interpreter or shell (`/^(python|node|ruby|sh|bash)\b/`, `npm run`) with a note.
- Single-stage classifier: add a stage-1 call with `max_tokens: 1` and a yes/no instruction using the same system prompt, and run the current structured call only on "yes".
- No environment or allow-exception slots: add `guardrail.environment: string[]` (trusted hosts/orgs) and `guardrail.allowExceptions: string[]` to the config, render them in the classifier prompt, and add `GET /api/guardrails/defaults` that dumps the built-in rule groups.
- No escalation counter: track consecutive and total denials per role in `AgentLoop`, pause the run with an `approval.requested` after 3 consecutive or 20 total, and show the counter in the Guardrails tab.
- Injection probe is a regex: when `sniffInjection` fires, run a one-shot classifier call over the output before deciding to wrap, and badge the CallRow ("flagged") instead of a separate note row.
- Scout delegation is unchecked: classify the scout question on dispatch in auto mode and attach the scout's tool-call count and any sniff hits to its returned answer.
- Miss rate is undocumented: add a line to the Guardrails tab and README stating that the classifier is single-stage and unmeasured, with a link to the lesson's 17% figure.
- Payloads are judged piecemeal: when `bash` executes a file written earlier in the same phase, prepend that file's content to the classifier input.
