## Gaps
- The harness holds state: persist `builderHistory` (direct) or `builderSession` (SDK), `features` and `contract` to the run dir after each phase so an `Orchestrator` can be rebuilt from disk and the log is the only state.
- No resume: add `RunManager.resume(runId)` that rebuilds the orchestrator from the saved phase state and continues at the last `phase.started`, instead of `markInterrupted` failing the run.
- The agent cannot reread the session: a deferred `read_log(from, to)` tool returning narrated events from the run's JSONL, filtered to the caller's role.
- Credentials in the SDK hand: pass `ANTHROPIC_API_KEY` to the subprocess only when no Claude Code login exists, point `CLAUDE_CONFIG_DIR` at a scoped copy, and document that the SDK Bash tool inherits the user's files.
- No failure taxonomy: add `kind: "model" | "tool" | "transport" | "harness"` to the `error` event and set it at each emit site; filter by it in the Transcript.
- Which hand is invisible: add `sandboxed: boolean` to `tool.result` from `ToolContext.sandbox` and badge it in `CallRow`.
- One brain per process: allow parallel repeats when each trial gets its own `git worktree`, with a per-workspace lock otherwise.
