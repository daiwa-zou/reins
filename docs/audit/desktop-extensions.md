## Gaps
- Workspace skills are trusted silently: ask once per workspace before indexing `.reins/skills` and `.claude/skills` (approval kind `skill`), and let `$REINS_HOME/settings.json` carry `skills.block: string[]` and `skills.allowWorkspace: boolean`.
- No skill manifest or lint: add `version:` and `requires:` (tools it expects, e.g. `bash`) to `SKILL.md` frontmatter, show them on the Skills card, and extend `lessons:check` to a `skills:check` that fails on a missing description or an unknown required tool.
- Secrets in a plain file: store the API key with the macOS `security` CLI (or `keytar`) when available and keep `settings.json` as the fallback, saying which is in use in Settings.
- Sandbox availability is invisible: render `info.sandboxAvailable` in New run next to the OS sandbox switch ("inert on this platform") and in the Guardrails tile.
- Formats are unversioned: add `schemaVersion` to `events.jsonl` lines (or the first event), `config.json` and `presets.json`, and document them in `docs/configuring.md`.
