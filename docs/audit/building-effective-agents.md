## Gaps
- Patterns are not composable: let `RunConfig` choose a `pipeline` preset (`agent-only`, `build+evaluate`, `full`) by pre-setting the component switches, and add a `voting` option that runs the evaluator N times and passes on a configurable majority.
- Raw request is not inspectable: emit a `request.sent` event (system prompt hash and text once per phase, tool names, betas) and render it in the Transcript under "Phases & turns".
- Tool workbench is missing: add `POST /api/tools/:name/try` that runs a tool against a scratch workspace and a small panel in the Harness tab to exercise schemas with sample inputs.
- Tool definitions are untested: add `registry.test.ts` cases for each tool's happy path and its documented error message.
- No voting threshold: see pipeline preset above; expose `evaluatorVotes` and `passThreshold`.
- Everything defaults on: add a "minimal" preset in the New run dialog that enables only the builder, narration and guardrails, so the measured path starts simple.
- Human review after a passing evaluation is optional and off: default `pauses.afterEvaluation` to true for the first run on a workspace.
