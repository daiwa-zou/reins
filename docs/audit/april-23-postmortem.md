## Gaps
- Context operations lack a trigger and a payload: include the configured threshold and `promptTokens` at the moment of the edit in `context.compacted`/`context.cleared`, and list the cleared `tool_use_id`s so the Transcript can mark them.
- No anomaly alert: in `derive.ts` flag a run when `context.cleared` fires on three consecutive turns or inside a turn that has an unresolved `tool.called`, and surface it as a warn note in the Stage.
- No resume/idle tests: add a `claudeCodeLoop.test.ts` case that constructs the loop with `resumeSessionId` and asserts `resume` is passed, and a `loop.test.ts` case that queues a steer while a tool call is pending.
- Active betas are not in the trace: add `betas` and `contextManagement` edit types to `turn.finished`.
- No prompt version: hash `systemPromptFor(...)` output per role and include it in the Environment note and `turn.finished`, so a prompt edit is joinable to a trial set.
- No model-gated prompt lines: let `systemPromptFor` accept the role's model and keep per-model extras in a `Record<modelPrefix, string[]>` so quirk fixes cannot leak to other models.
- No per-model/effort segmentation: record `effort` on `Trial` and let the Reliability tab split a set by model, effort and harness version.
- No CI: add a workflow running `npm run typecheck` and `npm test` on every PR, and a scripted `claude -p` review step over the diff.
- No feedback path: add a "Report this run" action that bundles config + events into `~/.reins/reports/`.
