## Gaps
- No checkpoints: before each `write_file`/`edit_file` (and in `canUseTool` for Write/Edit on the SDK engine) copy the previous content to `$REINS_HOME/runs/<id>/checkpoints/<seq>/<path>` and emit `file.checkpoint`; add a "Restore files to here" action on the scrubber that writes them back, leaving the conversation untouched, and say on the card that shell side effects are not restored.
- No managed background processes: add `start_process(command)` / `stop_process(id)` tools that keep a child alive for the phase, stream its tail into `tool.progress` events, and kill it at phase end; the Stage shows a "running processes" strip.
- No user hooks: support `.reins/hooks.json` (`afterEdit`, `beforeCommit`, `beforeFinish` commands with timeouts) executed by the orchestrator, each result logged as a `note` and a failing `beforeFinish` returned to the builder instead of finishing.
- Scouts are not available on the SDK engine: implement `delegate_scout` there with a nested `query()` using read-only tools, returning only the final text, so both engines share the component.
- No steer history: keep the last 20 operator notes per browser in `localStorage` and cycle them with the up arrow in the steer box; show the feed's past notes as suggestions.
- Diffs are per phase: emit `files.changed` after every write tool call (cheap `git diff --numstat` on the touched path) so the Changes tab updates per edit.
