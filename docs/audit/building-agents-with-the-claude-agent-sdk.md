## Gaps
- Scouts are missing from the SDK engine: register `delegate_scout` in the in-process MCP server (`claudeCodeLoop.ts:45`) and implement it with a nested read-only `query()`, or allow the SDK's `Agent` tool and map its `parent_tool_use_id` messages to a scout role instead of dropping them (`claudeCodeLoop.ts:235,262`).
- No preservation hook for compaction: add `context.preserve: string` to `RunConfig`, pass it as the compaction instruction where the API allows it, and append it to the handoff note on reset.
- No MCP integration: add `mcpServers` to `RunConfig` and surface their tools as deferred entries in `ALL_TOOLS` (direct engine) and `options.mcpServers` (SDK engine).
- No harness-owned lint feedback: run the workspace's configured lint/typecheck (from `package.json` scripts) after each `write_file`/`edit_file` burst and return the first error line as a tool `note`.
- No screenshots: add a deferred `screenshot` tool (Playwright, two viewports) available when the contract names a URL, and show the images in the Stage.
- The judge is not cost-gated: expose `evaluator` budget share in the config and skip the evaluation phase when all hard criteria have a shell `verify` that the builder already ran green (record it as "verified by command").
- No failure-to-eval loop: add "Save as task" on a failed run that writes the task, workspace and contract to `~/.reins/tasks/` for repeat trials.
- Coding assumptions are baked in: move git/test preamble lines from `BUILDER` into a `coding` profile selected by config, with a `general` profile that skips commits and baseline test runs.
