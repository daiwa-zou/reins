## Gaps
- Default contradicts the post's 2025-12-15 update: set `thinkTool.defaultOn` to false in `shared/components.ts:153` (or make the Careful profile the only one that turns it on) and record in `assumption` that current models with extended thinking rarely need it.
- Think rows are not distinct: in `feedGroups.ts` treat `think` as flagged (never grouped) and give it its own collapsible "reasoning" row in `Stage.tsx`, like native thinking.
- No brainstorm nudge on failure: when `lastEval` exists in `orchestrator.ts:234`, prepend "Before editing, use think to list at least two candidate causes for each failed criterion and pick one."
- No harness-level "assess before acting": in `loop.ts:402-405`, when a result is truncated or `ok === false` and the next turn's first tool is side-effecting (bash, write_file, edit_file), add a one-line user message asking for a `think` call first.
- Think usage is unmeasured: count `think` calls per role in `derive.ts` and show "N think calls · M output tokens" on the Context tab so the cost trade-off is visible per run.
